Limen Studio Publisher

Limen Studio Publisher is a private, first-party tool used by the owner of the YouTube channel Limen (@Limenind) to upload the channel's own videos, thumbnails, captions and playlist entries, and to read the channel's own analytics, using the YouTube API Services.

The tool has a single user (the channel owner) and is not offered to the public.
