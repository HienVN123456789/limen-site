Privacy Policy

Last updated: November 4, 2026

Limen Studio Publisher ("the tool") is a private tool operated by the owner of the YouTube channel Limen (@Limenind). It has one user, the channel owner, and is not offered to the public.

YouTube API Services

The tool uses YouTube API Services. By using the tool, the owner agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data the tool accesses

After the channel owner grants permission through Google's OAuth consent screen, the tool uses the YouTube Data API and the YouTube Analytics API to: upload the owner's videos and set their titles, descriptions and visibility; set thumbnails; upload caption tracks; add videos to the owner's playlists; post one discussion comment per video on the owner's own channel; read the privacy status of the owner's own videos; and read aggregate analytics of the owner's own channel. The tool also uses the Gmail API only to send a summary email to the owner.

Data we collect and store

The tool does not collect personal data about viewers or any other person. It stores locally on the owner's computer only: the OAuth refresh token (in the macOS Keychain), video IDs and upload timestamps of the owner's own videos, and weekly aggregate channel metrics used for the owner's internal review.

Sharing

We do not sell, share, transfer or disclose YouTube API data or Google user data to any third party.

Retention and deletion

Stored metrics are kept only for as long as the owner needs them for internal reporting and can be deleted by the owner at any time by deleting the local files. Deleting the OAuth token from the macOS Keychain removes the tool's ability to access the account.

Revoking access

The channel owner can revoke the tool's access to the Google account at any time at security.google.com/settings/security/permissions. Once access is revoked, the tool can no longer access any YouTube data.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Contact the channel through its YouTube page: @Limenind.
